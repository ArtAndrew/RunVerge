# Contributing to RunVerge

Start with the limited alpha profile in README.md and docs/QUICKSTART-ALPHA.md. Report installation problems, confusing workflows and whether a result helped you complete a real task. Feedback on a second use is especially valuable.

Use the issue templates. Never submit credentials, database URLs, private source documents or unredacted logs. The alpha is intended for local test data; recovery and migration of alpha installations are not promised.

Before proposing a large feature, open an issue explaining the user problem and a small demonstrable result. Changes to permissions, financial accounting or external action dispatch require failure-case checks and independent review. Documentation and small presentation changes need appropriately small checks.

Server, CLI and web code use Elastic License 2.0. Client SDKs and examples use Apache-2.0; preserve their boundaries and existing notices. See docs/LICENSING.md.
